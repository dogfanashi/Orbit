# Orbit Website

A complete static website for the Orbit Discord bot.

## Files
- `index.html` — homepage
- `commands.html` — command reference
- `terms.html` — Terms of Service
- `privacy.html` — Privacy Policy
- `styles.css` — site styling
- `assets/orbit-logo.png` — Orbit logo

## Before publishing
Open `index.html` and replace the two `#` button links with:
1. Your real Orbit bot invite URL
2. Your Orbit support server invite URL

The Terms and Privacy pages are templates. Make sure the Privacy Policy accurately describes what your actual bot stores/collects before publishing.

## Vercel
Upload this folder to GitHub, then import the repository in Vercel. No build command is needed for this static site.
