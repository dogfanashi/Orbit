PERMISSION HIERARCHY

How Orbit permissions work

Orbit uses Discord permissions, server roles, and Orbit's custom moderator-role system to determine who can use staff commands.

👑
Server Owner Full access to Orbit and server configuration
↓
🔴
Administrator Administrative, configuration, and moderation access
↓
🟦
Manager Server management and moderation access
↓
🛡️
Moderator Moderation and member-management access
↓
👤
Member General, economy, games, utility, and social commands

Server owners can designate additional moderator roles using /addmod. Orbit also respects Discord's permission and role hierarchy.

🔐 PERMISSIONS

Built around Discord's permission system.

Orbit's staff commands are restricted according to server permissions, Orbit's configured moderator roles, and Discord's role hierarchy. Orbit does not override Discord's permission system.
