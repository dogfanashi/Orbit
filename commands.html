Orbit Commands

Explore Orbit's commands by permission level. Commands are automatically protected according to Discord permissions and Orbit's server-specific moderator system.

PERMISSION HIERARCHY

Who can use Orbit?

👑
Server Owner Full access to Orbit
↓
🔴
Administrator Full administrative and moderation access
↓
🟦
Manager Server management and moderation
↓
🛡️
Moderator Moderation and member management
↓
👤
Member General and public commands

Orbit respects Discord's permission system and role hierarchy. Server owners can also designate custom moderator roles using /addmod.

👤 MEMBER

Member Commands

Commands available to regular members of the server.

/modules View available Orbit modules.
/tags View available server tags.
/tag View or use a server tag.
/star View starboard information for a message.
🛡️ MODERATOR+

Moderation Commands

Commands for moderators and authorized staff members.

/warn Warn a member.
/warnings View warnings for a member.
/clearwarn Clear warnings for a member.
/delwarn Delete a warning.
/unwarn Remove a warning.
/mute Mute a member.
/unmute Unmute a member.
/undeafen Undeafen a member.
/kick Kick a member.
/softban Softban a member.
/ban Ban a member.
/ban save Ban a member and save the moderation action.
/ban noappeal Ban a member without creating an appeal option.
/unban Unban a member.
/purge Bulk delete messages with advanced filtering options.
/members List members belonging to selected roles.
/modlogs View moderation logs for a member.
/moderations View active timed moderations.
/modstats View moderation statistics.
/case View a specific moderation case.
/reason Add or update a moderation case reason.
/duration Change the duration of a moderation action.
/note Add a private staff note to a member.
/notes View staff notes for a member.
/editnote Edit a staff note.
/delnote Delete a staff note.
/clearnotes Delete all notes for a member.
/lock Lock a channel.
/unlock Unlock a channel.
/lockdown Lock channels defined by moderation settings.
/slowmode Configure channel or user slowmode.
/role Add, remove, or toggle roles for members.
/temprole Assign a role for a limited amount of time.
/rolepersist Make a role persist when a member leaves and rejoins.
🟦 MANAGER+

Management Commands

Server management tools for authorized managers and administrators.

/addrole Create a new server role.
/delrole Delete a server role.
/rolecolor Change the color of a role.
/rolename Change the name of a role.
/mentionable Toggle whether a role can be mentioned.
/addemote Add a custom emoji to the server.
/setnick Change a member's nickname.
/announce Send an announcement through Orbit.
/announce everyone Send an announcement mentioning everyone.
/announce here Send an announcement mentioning active members.
/announce role Send an announcement mentioning a specific role.
/giveaway create Create a server giveaway.
/giveaway end End an active giveaway.
/giveaway reroll Reroll a giveaway winner.
/ignorechannel Toggle command usage in a channel.
/ignoreuser Toggle command usage for a user.
/ignorerole Toggle command usage for a role.
/ignored View ignored users, roles, and channels.
/customs enable Enable a custom command.
/customs disable Disable a custom command.
/customs show View a custom command.
/customs list List available custom commands.
👑 ADMINISTRATOR

Administrator Commands

High-level commands that control Orbit's configuration and permissions.

/addmod Add a server role to Orbit's moderator system.
/delmod Remove a role from Orbit's moderator system.
/listmods List all configured Orbit moderator roles.
/module Enable or disable an Orbit module.
/command Enable or disable an Orbit command.
/prefix View or configure the server's command prefix.
/diagnose Diagnose a command or module for potential problems.
SECURITY & PERMISSIONS

Built around Discord's permissions.

Orbit does not grant users permissions they do not already have. Moderation actions are subject to Discord permissions, Orbit's configured moderator roles, and Discord's role hierarchy.
