Orbit Commands

A starting command reference for Orbit. Add or remove commands as your bot develops.

/helpView Orbit's available commands.
/pingCheck Orbit's response time.
/serverView useful server information.
/userinfoView information about a member.
/warnIssue a moderation warning.
/timeoutTemporarily restrict a member.
/kickRemove a member from the server.
/banBan a member from the server.
/clearModerate messages in a channel.
/ticketCreate or manage a support ticket.
/announceCreate a server announcement.
/settingsConfigure Orbit for your server.
